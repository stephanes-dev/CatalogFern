# CatalogFern

Provides a simple and centralized catalog system for tracking and organizing files on a local network.

With CatalogFern, you get a lightweight tool that stays out of your way.

**What you get**

- Provides a simple and centralized
- catalog system for tracking and
- organizing files on a local

## Technology Stack

- python
- Modular architecture

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/CatalogFern.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

CatalogFern is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
